## Part A topic and the everyday picture (A1)

- Category in one general term: object storage (blob storage).
- Everyday picture: the cloakroom (from the old page): you hand in the whole coat and get a ticket; you cannot change a button on the hanger.
- The trade: any file of any size, any number of files, direct HTTP access, copies in several zones / no partial update, no search inside, no rename, no file lock; strong consistency on one key / no transaction over many keys.

## Known traps for Part A

1. A folder is not a folder: it is a prefix; rename is copy + delete (A3 "cannot" row and an ask box).
2. An object is replaced as a whole: no partial update, no append (A6), and concurrent writes are last-writer-wins without an error (A6, `cond` sim).
3. Small objects cost per request and do not transition below 128 KB by default (A8, B5).
4. Versioning keeps every version and every version is paid; a DELETE adds a marker (A7).
5. Lifecycle is asynchronous and not exact to the second (A8).
6. S3 Select and S3 Object Lambda are closed to new customers (B5, M5).
