What happens

  1. Aurora: one transaction updates the stock and writes the order
  2. DynamoDB: empty the cart
  3. ElastiCache: add the amount to the live leaderboard
  4. Keyspaces: record a purchase event
  5. InfluxDB: count one order for the operations chart
  6. Neptune: add BOUGHT edges for recommendations

A production system sends these updates as events through a queue (for example SQS or EventBridge). Here the browser makes the calls one by one, so the panel can show each of them.
