E2E tutorials: one Engine at a time.

Each tutorial starts from first principles: how the Engine puts the data on disk or in memory. Then it uses the real Lale Market data. You read a concrete table, predict the result of a query, run the query on the live Engine and compare. Checkpoint questions make sure that you understand each part before you continue.

The order goes from the most familiar model (relational tables) to the special models. You can read them in a different order. The glossary defines each term that the tutorials use.
