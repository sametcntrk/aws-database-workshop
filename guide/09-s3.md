# Modül 9 - Amazon S3 (Unstructured, Blob)

- **Sitedeki bölüm:** bütün ürün görselleri ve satıcı paneli (`/seller`)
- **Bağlantı:** HTTPS 443, S3 API, IAM SigV4 (şifre yok). Trafik S3 gateway endpoint'inden geçer, NAT kullanmaz.
- **Neden S3?** Görseller ve dosyalar veritabanına değil, nesne deposuna konur. S3 neredeyse sınırsız büyür,
  her nesneyi en az 3 AZ'de saklar ve nesneyle birlikte metadata tutar.

## 9.1 Bucket

**S3 → Create bucket**

| Alan | Değer |
|---|---|
| Bucket type | General purpose |
| Bucket name | `dbws-images-<ACCOUNT_ID>-eu-central-1` |
| Object Ownership | ACLs disabled (Bucket owner enforced) |
| Block all public access | açık |
| Bucket Versioning | Enable |
| Default encryption | SSE-S3 |

Bucket oluştuktan sonra iki ayar yapın:
- **Management → Create lifecycle rule**: Name `expire-old-versions`, bütün nesneler,
  **Permanently delete noncurrent versions of objects**: 1 gün.
- **Permissions → Bucket policy**: yalnızca TLS ile erişime izin verin:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    { "Sid": "DenyInsecureTransport", "Effect": "Deny", "Principal": "*", "Action": "s3:*",
      "Resource": ["arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1",
                   "arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1/*"],
      "Condition": { "Bool": { "aws:SecureTransport": "false" } } }
  ]
}
```

## 9.2 Engine App

| Adım | Değer |
|---|---|
| E1 | `dbws-sg-app-s3` |
| E2 role | `dbws-app-s3-eu-central-1` |
| E3 | Subnet `dbws-app-a`, IP `10.20.10.12` |
| E4 | `dbws-tg-s3`, health check `/s3/health` |
| E5 | Path `/seller`, `/s3/*`, öncelik **90** |

```json
{
  "Version": "2012-10-17",
  "Statement": [
    { "Effect": "Allow", "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1" },
    { "Effect": "Allow", "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
      "Resource": "arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1/*" },
    { "Effect": "Allow", "Action": "secretsmanager:GetSecretValue", "Resource": "<dbws/admin secret ARN>" }
  ]
}
```

```bash
ENGINE=s3
URL_PREFIX=/s3
AWS_REGION=eu-central-1
AWS_DEFAULT_REGION=eu-central-1
ADMIN_SECRET_ARN=<dbws/admin secret ARN>
BUCKET_NAME=dbws-images-<ACCOUNT_ID>-eu-central-1
```

## 9.3 Doğrulama

1. Admin Console'da S3 satırındaki **Seed** düğmesine basın. 200 ürün fotoğrafı (Wikimedia Commons, serbest lisanslı) yazar ve lisans bilgisiyle yüklenir. Mağazadaki ürün kartlarında fotoğraflar görünür.
2. `/seller` sayfasında küçük bir görsel yükleyin. Panelde `PutObject` çağrısını, metadata'yı ve yeni version id'yi görün.
3. Aynı adla bir dosyayı tekrar yükleyin. S3 eski sürümü saklar.
4. **Through the Engine App** ve **Presigned URL** düğmelerini karşılaştırın.
   Presigned URL'de tarayıcı görseli doğrudan S3'ten indirir ve bucket yine private kalır.
