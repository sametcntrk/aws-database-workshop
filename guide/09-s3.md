# Modül 9 - Amazon S3 (Unstructured · Blob)

**Domain dilimi:** ürün görselleri. **Read:** bir prefix'i listele, nesneleri metadata'larıyla oku, sayfada göster.
**Bağlantı:** HTTPS 443, S3 API, IAM SigV4 (şifre yok), **S3 gateway endpoint** üzerinden (NAT yok).

## 9.1 Bucket

**S3 → Create bucket**

| Alan | Değer |
|---|---|
| Bucket type | General purpose |
| Bucket name | `dbws-images-<ACCOUNT_ID>-eu-central-1` |
| Object Ownership | ACLs disabled (Bucket owner enforced) |
| Block all public access | açık |
| Bucket Versioning | Enable |
| Default encryption | SSE-S3 |

Sonra:
- **Management → Create lifecycle rule**: Name `expire-old-versions`, bütün nesneler, **Permanently delete noncurrent versions of objects**: 1 gün.
- **Permissions → Bucket policy**: sadece TLS ile erişim:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    { "Sid": "DenyInsecureTransport", "Effect": "Deny", "Principal": "*", "Action": "s3:*",
      "Resource": ["arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1",
                   "arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1/*"],
      "Condition": { "Bool": { "aws:SecureTransport": "false" } } }
  ]
}
```

## 9.2 Engine App

| Adım | Değer |
|---|---|
| E1 | `dbws-sg-app-s3` |
| E2 role | `dbws-app-s3-eu-central-1` |
| E3 | Subnet `dbws-app-a`, IP `10.20.10.12` |
| E4 | `dbws-tg-s3`, health check `/s3/health` |
| E5 | Path `/s3`, `/s3/*`, öncelik **90** |

```json
{
  "Version": "2012-10-17",
  "Statement": [
    { "Effect": "Allow", "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1" },
    { "Effect": "Allow", "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
      "Resource": "arn:aws:s3:::dbws-images-<ACCOUNT_ID>-eu-central-1/*" }
  ]
}
```

```bash
ENGINE=s3
URL_PREFIX=/s3
AWS_REGION=eu-central-1
AWS_DEFAULT_REGION=eu-central-1
BUCKET_NAME=dbws-images-<ACCOUNT_ID>-eu-central-1
```

## 9.3 Doğrulama

`/s3/` → **Seed** (PNG görseller, `products/<kategori>/<ürün>.png`) → **Read** (görseller sayfada).
S3 konsolunda bir nesneyi açıp **Metadata** bölümünde `x-amz-meta-*` alanlarını görün. Seed'i tekrar çalıştırınca **Show versions** ile eski sürümleri görün.
